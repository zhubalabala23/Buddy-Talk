# BuddyTalk

BuddyTalk adalah platform pembelajaran interaktif berbasis web yang dirancang khusus untuk siswa kelas 5 Sekolah Dasar guna mempelajari nilai-nilai karakter baik. Platform ini menggabungkan media cerita video/audio, permainan tantangan interaktif (challenge), dan perekaman suara untuk refleksi mandiri.
Aplikasi ini juga dilengkapi dengan panel khusus untuk guru guna memberikan penilaian berdasarkan rubrik terstandar serta memantau perkembangan belajar siswa secara real-time.

## Alur Belajar Siswa
Aplikasi ini menerapkan alur belajar terstruktur (flow constraints) untuk memastikan pemahaman materi yang optimal sebelum siswa dapat lanjut ke tahap berikutnya:
1. **Memilih Topik Cerita**: Siswa memilih salah satu topik karakter baik (Jujur, Rajin, Ramah, Pemberani, atau Persahabatan) melalui halaman Beranda.
2. **Kriteria Penilaian**: Siswa diarahkan untuk membaca kriteria penilaian dari guru terlebih dahulu.
3. **Menyimak Materi**: Siswa mendengarkan atau menonton video cerita karakter sampai selesai. Siswa tidak dapat membuka halaman Challenge jika video materi belum selesai ditonton.
4. **Menyelesaikan Challenge**: Siswa menyelesaikan 4 tahap permainan interaktif:
   * **Character Detective**: Menebak sifat tokoh berdasarkan memo petunjuk.
   * **Picture Sorting**: Mengelompokkan kartu perilaku baik dan kurang baik.
   * **Story Puzzle**: Menyusun urutan alur cerita secara kronologis.
   * **Buddy Words**: Memilih kata kunci positif yang sesuai dengan isi cerita.
   Siswa tidak dapat mengakses halaman Rekam Suara jika tantangan challenge belum diselesaikan secara tuntas.
5. **Rekam Suara (Refleksi)**: Siswa menceritakan kembali nilai moral cerita dengan bahasa sendiri menggunakan fitur perekam suara langsung pada web.
